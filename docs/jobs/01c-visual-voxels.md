# Increment 01c — Visual quarter voxels

The creative director approved small cubes for visual appearance while keeping the full-block gameplay grid. Half-block and quarter-block building pieces are a planned separate feature; individual decorative cubes are not editable.

Deliver a bounded visual experiment on the existing finite scene, using quarter-block shader surface detail and native-meshed quarter-unit tree/ground decorations. Keep the simulation coarse. Use shared meshes and distance limits rather than one node per decorative cube. Keep auto-jump and joystick fixes functional.

Validate native detail geometry, shared mesh reuse, bounded instances, collision behavior and existing control tests. Render/inspect a capture and build/sign/verify the updated ARM64 APK. The director's reported 120 fps on previous versions is a baseline, not evidence of the new version's performance. Record startup/mesh counts and retain physical phone validation as outstanding. Commit and push through the lead and provide the GitHub APK download.
